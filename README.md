# NNVis
O NNVis é um projeto open-source focado na visualização gráfica e interativa de redes neurais. Com ferramentas para analisar camadas, neurônios, pesos e ativações, este repositório é dedicado a pesquisadores, estudantes e entusiastas de IA que querem entender como as redes neurais funcionam por dentro.

## Momento atual: 
No momento estamos na etapa final do gerador da arquitetura (padrão), faltando as etapas intermediárias, por exemplo, desenvolver a lógica do alternador de função de ativação. A próxima grande etapa será desenvolver a lógica de propagação, entrada de valores, com tudo isso finalizado, a retropropagação.
